# KidsTubeTV 设置 UI V2 高密度实现

**依据：** 用户确认的《KidsTubeTV_设置界面_高密度V2_交互审查版.html》（2026-11-16）。该 HTML 预览仅模拟操作，本文件记录在 Android 原生 Views 中对应的已实现界面结构。开发必须保留家长 PIN、订阅安全存储和应用独享 VPN 的业务边界。

## 电视横屏

- 固定约 205dp 左侧导航：概览 / 应用网络 / YouTube 账号 / 儿童内容 / 家长与安全；右侧主区域包含页面标题、摘要、可滚动高密度功能区。
- 一页展示并排两组 50% 功能面板。屏幕逻辑宽度不足 720dp 时改为单列防拥挤。
- 操作卡片缩减至约 62dp 最小高度，字体与间距更紧凑；遥控器 D-pad 聚焦仍有明显的高对比描边。
- BACK：高级操作、对话框及订阅编辑优先关闭；其它分区返回概览，概览再退出。

## 手机界面

- 标题行下方固定可水平滚动五分类标签；分组上下堆叠，一次浏览同页更多常用操作。
- 卡片最小高度约 54dp，摘要统计为 2×2，不在手机上强行两列按钮。
- 仍保留触摸滚动、软键盘、返回及 PIN 守护；订阅输入只在家长主动展开时出现。

## 分区映射

| 页面 | 直接展示的内容 | 默认折叠 |
|---|---|---|
| 概览 | 网络/白名单/今日时长/每日限额，快速入口，观看规则，添加频道 | 无 |
| 应用网络 | VPN 连接与状态、添加/粘贴/保存订阅、导入 YAML、订阅检测、重新下载、自动更新周期、节点选择、诊断、仅代理本应用说明 | 重启 VPN、恢复旧配置、暂停 |
| YouTube 账号 | Google TV OAuth、导入频道、API Key、白名单入口、网络和授权状态 | 复杂 OAuth 参数仍在单独 Google 页 |
| 儿童内容 | 频道白名单、视频白名单、每日限额、搜索/连播开关、今日统计 | 精确允许/禁止的视频 ID |
| 家长与安全 | 修改 PIN、后台限时、前台闲置超时、观看历史、清除记录、脱敏诊断 | 无 |

## 订阅编辑隐私和生命周期

- 网络页的订阅输入默认隐藏。只有已验证的家长主动点击后，才读取并显示已存储地址；此时 `FLAG_SECURE` 禁止系统普通截图/录屏。
- **保存并下载**：先做 HTTPS URL 检查，然后写入 Keystore 保护的 `SettingsStore`，最后调用现有互斥更新流程。取消/返回：清空输入，不改变已有配置。
- 不传输 URL 到 Intent extras、状态 Bundle、普通日志；系统剪贴板可能由第三方读取，家长需知晓。
- 保留 `SubscriptionEditorActivity` 源码作为兼容旧入口，但 V2 家长网络页不再跳转至该 Activity。
- **功能验证边界：** 保存/下载操作保留既有逻辑；并未因此验证真实私人订阅可用或任何 YAML 都能被 Mihomo 加载。

## 回归清单

- [ ] 1920×1080 / 1280×720 TV：侧栏固定、双栏内容不越界，左右/上下方向键和 OK 可完整操作，焦点不跳至隐藏页面。
- [ ] 手机 360dp / 412dp：分类栏横向可滑动，统计 2×2，订阅页内编辑与软键盘不会盖住保存按钮。
- [ ] 分类快速来回切换，订阅 URL 已展开后转页、按返回、旋转屏幕，不能把 token 显示在截图或普通日志中。
- [ ] 使用无 token 的假 URL 验证 URL 提交按钮、错误提示和下载进度；首次网络权限仍使用 Android 原生 VPN 同意对话框。
- [ ] 频道与视频白名单、观看时长、搜索/自动连播修改能立即刷新当前摘要卡。
- [ ] 家长 PIN 锁定/后台短暂切换与过期仍正常；没有权限时敏感按钮不能继续执行。
- [ ] 连接状态异常时，应用网络页能够显示脱敏的错误与恢复入口；原生 YAML 导入、实际 Mihomo 启动和 Google 连接须另外实机验证。

## 源码

- `app/src/main/java/dev/kidstubetv/ui/SettingsActivity.kt`：五路由、概览/网络/账号/儿童/家长分组及功能回调。
- `app/src/main/java/dev/kidstubetv/ui/DenseSettingsUi.kt`：状态摘要、两栏面板、紧凑设置行、移动断点。
- `app/src/main/java/dev/kidstubetv/ui/SettingsDecor.kt`：可聚焦紧凑卡片样式。
- `app/src/test/java/dev/kidstubetv/ui/DenseSettingsLayoutPolicyTest.kt`：双栏/单栏、移动统计布局测试。
