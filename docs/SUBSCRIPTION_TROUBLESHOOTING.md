# Clash 订阅管理与更新失败排查（主线 libmihomo-android）

## 2026-11-13 与 FlClash 的兼容性修复

- 下载器依次使用 `FlClash`、`ClashMetaForAndroid`、`clash.meta`、`clash` 请求头，仅在 HTTP 403/406/415 或响应 HTML、Base64、无效 YAML 时尝试下一个客户端标识；HTTP 401（令牌错误）、429（限流）、网络超时及不安全配置不会重复尝试。
- 对常见 HTTPS `/api/v1/client/subscribe?token=…` 订阅地址的语法校验仍支持，**不会把任何真实 token 写入测试、日志或仓库**。
- 若在 KidsTubeTV 尚未建立 VPN 时网络无法访问该服务，而 FlClash 通过自身代理可以下载，需要先从服务商/可信客户端获取 Clash/Mihomo YAML，通过「下载失败？导入本地 YAML」或高级设置的文件导入功能使用。首次配置的启动循环无法靠更换 User-Agent 保证解决。
- 若显示「服务器返回 Base64/通用节点格式」，说明返回的不是可直接加载的 Mihomo YAML。本版本不会自动执行不受信任的在线订阅转换服务；应从服务商获取 Clash/Mihomo 专用配置。
- 若显示危险 `allow-lan` 或外部管理监听地址，会阻止导入，**不会为了兼容而开放电视局域网代理接口**。
- 从手机切换出去复制订阅链接、3 分钟内返回设置页时不应再次输入 PIN；浏览器/系统授权跳转仍有更严格限时。

## 最简单的操作路径

进入 KidsTubeTV 的 **☰ 菜单 → 家长设置（PIN）→ 网络 VPN**：

- **Clash 订阅地址 · 查看 / 编辑 / 复制**：原有 URL 不再以密码形式隐藏。进入后可检查、长按选择、复制、粘贴或编辑完整链接。按钮提供“仅保存地址”与“保存并更新”。
- **↻ 更新已保存的订阅**：已有 URL 后一键重新下载并检查，无需再次输入。
- **从文件导入 Clash YAML（备用）**：首次没有配置或更新失败时自动显示。手机可从下载目录选择 YAML，电视可从 U 盘选择。
- **连接 VPN**：首次下载成功后启动；更新成功但 VPN 已运行时，可按弹窗“立即应用”，主动重连加载新配置。

成功的新配置会覆盖旧配置，下载/解析失败时**保留最后一次成功的 YAML**；如果用户仅保存链接，新 URL 会加密存储以供下次更新，但当前核心不自动切换到未经验证的配置。

## 并发安全与配置生效时机（2026-11-11）

- 通过 PIN 保存新订阅 URL 时，地址立即安全保存；**只有下载成功并通过 YAML 校验才替换磁盘里的当前配置**。
- 手动/自动订阅更新共用互斥门控；下载期间如果家长更换 URL、使用本地 YAML 或恢复备份，旧请求会失效，不能在网络恢复后覆盖新的配置。
- URL 比较、版本校验、写入 YAML、清理旧节点选择和更新时间在同一配置锁内完成；失败保持之前的 YAML 和备份。
- 更新完成并不意味着运行中的 JNI 核心立即重载，需在家长中心重启 VPN 才会使用新配置。自动更新也不会中途强制断开正在播放的视频。

## 失败原因和对应动作

| 状态提示 | 原因与操作 |
| --- | --- |
| DNS 解析失败 | 订阅域名未解析。先检查网络；首次导入 VPN 尚不可用时尝试更换网络，或者从本地 YAML 引导启动。 |
| TLS 握手失败 | 证书/系统日期或 HTTPS 服务异常，不应关闭证书校验。 |
| 连接超时 | 当前网络或已选代理节点无法访问订阅服务，可切换网络/节点后重试。 |
| HTTP 401/403 | 令牌失效、过期或服务商校验客户端。下载器会尝试常见 Clash UA 标识，仍失败需查看服务商 Clash 格式地址。 |
| HTTP 404/429/5xx | 地址不存在、限流、服务端故障。确认地址/等待。 |
| HTML 页面或 Base64 | 返回的是登录/欢迎页面或通用 V2Ray 节点，而不是 Clash/Mihomo YAML；应到服务商后台重新复制 Clash 链接，不要上传到第三方在线转换工具。 |
| YAML 格式错误/危险 LAN 接口 | 格式与本应用安全要求不兼容。不会绕过儿童场景的配置保护。 |
| 4 MiB 超限 | 服务商节点列表太大，需使用更精简配置。 |

自动更新失败的安全类别会保留并在家长网络设置中显示；不会显示原始错误体、完整 URL 或订阅 token。诊断依赖真实 Android 设备网络，**CI 只能证明代码路径通过模拟网络、单元测试与构建**，不能证明具体服务商的链接可用。

## 查看和复制订阅的隐私提示

虽然入口受家长 PIN 保护，**完整订阅 URL 往往包含令牌，等同于访问凭据**。按“复制地址”会将其放入 Android 剪贴板；部分系统/第三方输入法可看到剪贴板历史。请只在受信任设备上操作，不要把完整 URL 放进工单、日志、截图或聊天记录中。
