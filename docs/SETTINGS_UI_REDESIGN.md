# KidsTubeTV 设置 UI 重构方案（TV 遥控器 + Android 手机）

> 版本：2026-11-12 · 状态：第一阶段已实现到 Android Views / Kotlin 源码，CI 状态以当前提交对应的 GitHub Actions 为准。此文档同时是交互规则与真机验收清单。

## 1. 设计目标与边界

- **简单：** 默认只展示当前状态和最常用操作，不要求用户了解 Clash 全局模式、TUN 参数或代理端口。
- **相同功能、不同交互：** 手机用触控/键盘，电视用 D-pad/OK；复用同一份配置存储、VPN、频道白名单和 Google 认证。
- **父母可控：** 设置区域仅 PIN 解锁后可用，订阅 URL、OAuth Secret 不出现在儿童页、普通日志或 Intent extras。
- **稳定：** 主要结构仍使用 QWidget 风格的 Android Views（Kotlin），不迁移 Compose 或重写业务服务；支持 Android 9 / API 28。
- **固定应用专用 VPN：** 系统 \`VpnService.Builder.addAllowedApplication(packageName)\` 只允许 KidsTubeTV 包名进入 VPN。Android 同时通常只运行一个 VPN，不能误解成兼容其它正在使用的 VPN 客户端。

## 2. 信息架构（五分区）

| 路由 | 主要功能 | 默认可见内容 | 二级入口 |
| --- | --- | --- | --- |
| 概览 / \`OVERVIEW=0\` | 配置状态和快捷导航 | 下一步引导、网络、YouTube、内容和 PIN 状态 | 其它四分区 |
| 应用网络 / \`NETWORK=1\` | 只代理当前 App | 连接状态、连接/检测、添加/更换订阅 | 展开的更新、节点、导入、诊断、暂停 |
| YouTube 账号 / \`YOUTUBE=2\` | Google OAuth / API Key | 账号状态、授权入口、API Key | \`GoogleAccountActivity\` |
| 儿童内容 / \`CONTENT=3\` | 白名单和观看习惯 | 已批准数量、添加频道、时长 | 视频 ID、搜索、自动播放 |
| 家长与安全 / \`PARENT=4\` | PIN 与数据维护 | PIN 状态、修改 PIN、清除记录 | 设备与网络诊断 |

兼容已有入口：过去 \`SettingsActivity.EXTRA_SECTION=1\` 指向网络页，仍然如此。首次无代理配置从网络页进入；已有配置默认从概览进入。

## 3. 电视布局（遥控器）

\`\`\`text
+-----------------------+-----------------------------------------+
| KidsTubeTV            | 设置概览 / 应用网络 / ...                |
| 家长中心               | 摘要 / 下一步设置                        |
|                       |                                         |
| [概览]                | [可聚焦大卡片 1]                        |
| [应用网络]            | [可聚焦大卡片 2]                        |
| [YouTube 账号]        | [可聚焦大卡片 3]                        |
| [儿童内容]            | [更多设置 ... 默认折叠]                  |
| [家长与安全]          |                                         |
|                       |                                         |
| [返回儿童首页]        |                                         |
+-----------------------+-----------------------------------------+
\`\`\`

- 使用 TV 模式检测（\`UiDevice.isTelevision\`）而不按横屏误判电视。
- 左侧导航宽约 244 dp，五项高 65 dp；右侧操作卡按现有 \`SettingsActionTile\` 78 dp 及明显的焦点边框。
- **OK：** 在左栏选择目标分区，并将焦点转到右侧第一项；**LEFT：** 右侧可聚焦操作项返回当前左栏；**UP/DOWN：** 由 Android 焦点系统在卡片间移动。
- **BACK：** 从任意详情到概览，概览再退出家长中心。打开的系统对话框由系统优先处理 BACK。
- 展开高级项后重新绑定左侧焦点目标；滚动容器配合焦点自动滚动，避免不可见元素吞键。

## 4. 手机布局（触控）

\`\`\`text
+---------------------------+
| ‹ 首页       设置概览      |
| 今日已看 / 已批准频道     |
| [下一步配置卡]            |
|                           |
| [应用网络  已连接 / 未连接]|
| [YouTube 账号  已授权?]   |
| [儿童内容  x 频道...]     |
| [家长与安全  PIN 已设置]   |
+---------------------------+

进入详情：
+---------------------------+
| ‹ 概览      应用网络       |
| [仅应用网络状态]           |
| [连接 / 检测网络]          |
| [添加或更换订阅]           |
| [更多设置 ...]            |
+---------------------------+
\`\`\`

- 手机使用固定顶部返回与动态页面标题，移除大号横向 TV 标签条。
- 概览纵向列表可直接点击进入详情，手机与 TV 调用相同 \`showSection\` / 业务回调。
- 旋转后通过 \`SAVED_SECTION\` 恢复当前分区；嵌入的资料仍由 \`SettingsStore\` 提供，不重复缓存 token。
- 子页返回优先回概览而非关闭整个设置。

## 5. 订阅编辑（独立 Activity）

\`SubscriptionEditorActivity\`：

- 由 \`SettingsActivity\` 在 PIN 会话有效时打开；AndroidManifest 中 \`exported=false\`，不允许其它 App 直接打开。
- TV 使用居中的 780 dp 内容列，进入先聚焦“返回网络设置”，**不会默认弹软键盘**；手机铺满屏幕、底部保留固定“保存并下载订阅”按钮。
- 编辑框为普通 URL 文本，可长按选择；辅助操作为“粘贴链接”、“复制链接”、“清空输入”，而不是复杂 YAML 配置。
- 输入先经 \`SubscriptionFormat.normalizeUrl\` 验证，只接受符合规则的 HTTPS 公共域名链接。
- 点击保存：先写入 Android Keystore-backed \`SettingsStore.subscriptionUrl\`，当 URL 变化时清理旧自动更新时间；然后仅返回 \`EXTRA_PROVIDER_CHANGED\` 布尔值。
- **不会通过 Intent 返回完整带 token URL。** SettingsActivity 重读 \`SettingsStore\` 后，仍使用原有互斥门控、YAML 验证与备份机制下载。
- 使用 \`FLAG_SECURE\` 防止此编辑屏幕被系统普通截图/录屏捕获；剪贴板的 token 仍可能被其它应用或输入法读取，需由家长注意清理。
- 下载成功：已连接时询问是否立即重连；尚未连接时，在家长会话有效且未手动暂停的条件下继续 VPN 授权/连接。
- 取消或返回：不更改已保存的订阅地址。
- 下载失败：保留上一个可用 YAML，在网络详情中展示脱敏错误原因，高级设置可从 U 盘导入。

## 6. UI 状态与文案

| 状态 | 概览 | 网络页操作 | 后续行为 |
| --- | --- | --- | --- |
| 无订阅 | 未连接 / 需设置 | 先添加订阅 | 打开独立编辑页 |
| 正在启动 | 连接中 | 正在连接 | 不重复触发 VPN |
| \`READY\`, 健康 \`UNKNOWN\` | 已连接 | 检测应用网络 | 异步 HTTPS 检测 |
| \`READY\`, \`ONLINE\` | 已连接 | 检测应用网络 | 其它应用保持系统路由 |
| \`READY\`, \`UNREACHABLE\` | 已连接，检测失败 | 检测应用网络 | 不据单一 URL 失败自动下线 |
| \`ERROR\` | 连接异常 | 手动连接 | 展示脱敏状态并允许诊断 |
| 手动暂停 | 未连接 | 手动恢复 | 不自动重连 |

**注意：** \`READY\` 表示 TUN 已建立，不能据此宣称节点、DNS、IPv6 或 YouTube IFrame 已通。

## 8. 验收清单

### 自动化检查

- \`gradle :app:lintDebug :app:testDebugUnitTest :app:assembleDebug\` 全部通过。
- TV/手机路由、网络历史索引与返回策略 JVM 测试通过。
- 完整 APK 含 \`SubscriptionEditorActivity\`，VPN 不出现全局路由配置切换。
- 检查 CI 生成的 APK 及 ABI、签名；构建成功不是设备测试。

### 电视人工验收

1. D-pad 五项导航 / 右侧第一卡进入 / 左键返回导航 / BACK 两级返回。
2. 进入更多设置、上下滚动到底、返回左栏，不出现焦点丢失。
3. 订阅编辑页输入框获得焦点后 Android TV 键盘能正常输入；取消后不会保存修改。
4. 保存合法链接后异步下载、成功后请求系统 VPN 授权；失败保留旧 YAML。
5. Google 账户配置、白名单、PIN 修改、历史清理和系统诊断全部入口仍在。

### 手机人工验收

1. 竖屏 320–420 dp：标题、概览卡片和底部保存按钮均不截断。
2. 横屏及旋转：仍在当前页，键盘升起/收起不会遮挡主按钮。
3. 复制、粘贴、清空后保存成功，返回网络状态；APP 不在系统日志中输出订阅 token。
4. Android BACK / 页面返回分区一致，儿童视频主页不会意外退出或误触家长设置。
5. 另装普通网络应用比较访问路线；**不得把另一个 VPN 客户端同时运行当成保证支持的场景**。

## 9. 非本轮范围与已知风险

- 无新增局域网 HTTP 上传、二维码输入桥、远程配置 API；避免将带 token 订阅广播到同网段。
- TV 系统软键盘与各厂商方向键行为、WebView 及 Google OAuth 仍需要 Android 9 雷鸟电视和真实手机测试。
- 当前设计直接使用 Android Views，后续若增加多级维护页面可把 \`SettingsActionTile\` 等抽成复用 View，不应强制在当前阶段切换 Compose。

## 10. 第二阶段实现：子页统一与请求生命周期（2026-11-12）

第一阶段重构完成后，本轮继续改造三个原来布局和行为分散的子页面：

| 界面 | UI 改造 | 业务与状态安全 |
| --- | --- | --- |
| Google TV 登录 | 统一固定返回栏、状态卡、授权与频道导入卡片；OAuth 客户端配置折叠，TV / 手机尺寸不同 | Client ID / Secret 仍使用 `GoogleTvAuth` 的安全存储；页面禁截屏，已保存 Secret 不展示；轮询仅在本次设备码导致的新授权生效后才报告成功 |
| 代理节点 | 默认策略说明、刷新、可选 Selector 组卡片；流量/测速默认折叠 | 查询、切换和测速回调通过 `LatestResultGate` 防止旧结果覆盖；离开再返回会重新查询 |
| 网络诊断 | 统一状态卡和「开始一键检测」主按钮；单项 HTTPS、凭据检测、脱敏报告折叠 | 离开页面使异步探测失效并复位正在检测标志，不会以旧请求覆盖新页结果 |

统一布局实现文件：`ui/SettingsDetailPage.kt`，负责：
- 手机全宽滚动布局、紧凑返回栏与触摸尺寸；
- TV 居中 880 dp 详情宽度、大焦点目标与默认主操作焦点；
- 主操作卡、状态卡、折叠区使用与设置首页一致的配色及焦点描边。

**订阅编辑旋转：** `SubscriptionEditorActivity` 声明 `orientation|screenSize|keyboardHidden`，手机横竖屏切换不会因为 Activity 重建而把用户未保存的完整 URL 传入系统状态 Bundle。仍需测试不同软键盘和极窄屏幕布局。

**后台授权：** `SettingsActivity` 在页面停止显示时不再因订阅下载完成弹出 VPN 授权请求；新配置依然写入安全存储，家长重新打开设置后可主动连接。

### 本轮新增验证场景
1. TV：Google 授权/诊断/节点页首个主操作可聚焦，返回按钮可被 D-pad 操作，展开折叠后列表可滚动到尾。
2. 手机：Google OAuth Secret 输入、复制设备码、从浏览器返回授权页以及独立订阅编辑横竖屏切换；键盘不能遮挡永久不可触及的操作。
3. 异步：节点列表请求期间 Home 再返回、诊断 API 验证中退出再重进、设备码过期/更换 Google 客户端，不出现错误成功状态。
4. 安全：订阅与 OAuth 凭据不会进入普通截图、Intent extras、日志；其它 Android 应用不进入 KidsTubeTV 的应用专属 VPN 隧道。
5. 仍需运行真实设备测试：Android TV OEM 键盘行为、Google OAuth、Mihomo TUN/DNS 和 IFrame 视频播放。

## 11. 2026-11-13 家长授权及订阅页面故障修复

- 家长 PIN 在应用短暂后台期间保留 180 秒；恢复时重新开启 120 秒前台无操作倒计时。离开超过宽限、进程死亡或主动锁定都要重新输入。
- 外部文件选择器与浏览器跳转继续使用本次 PIN 原始有效期，防止后台宽限成为额外授权通道。
- 订阅下载依次尝试常见 FlClash / Mihomo 客户端标识，在格式协商失败时使用下一标识，不会通过忽略 TLS 校验、关闭局域网安全保护或把 token 放入诊断日志来提高成功率。
- 网络页发生首次下载失败且没有 YAML 时，展示受保护的本地文件导入入口，方便家长从受信任的设备导入导出的 Clash 配置。
- 这些代码在单元测试中使用伪造 HTTP 响应，**未真实访问用户分享的私有订阅地址**。私密订阅在目标网络上的可达性仍需自行验收。
